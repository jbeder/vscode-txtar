# txtar for VS Code

VS Code syntax highlighter for [txtar](https://pkg.go.dev/golang.org/x/tools/txtar) archives, using VS Code's built-in grammars for each file.

To support a new file type, add it to the list in `syntaxes/txtar.tmLanguage.json`
and `package.json`.

Install with **Developer: Install Extension from Location...** in VS Code, then reload the window.
